# Python Calculator

A simple command-line calculator built with Python.

## Description

This project is a basic calculator that performs mathematical operations through a command-line interface. It was created as a Python practice project to improve my programming skills.

## Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Power (**)
- Modulo (%)
- Square root (sqrt)
- Calculation history
- Input validation and error handling
- Exit the program using `q`

## Technologies Used

- Python 3
- `math` module

## How to Run

1. Make sure Python is installed on your computer.
2. Download or clone this repository.
3. Open the project folder.
4. Run the following command:

```bash
python Calculator.py
```

## Usage

- Enter the first number.
- Enter the desired operator.
- Enter the second number (except for square root).
- Use `h` to view calculation history.
- Use `q` to exit the program.
