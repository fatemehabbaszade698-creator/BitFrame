# Rock Paper Scissors

A simple command-line Rock Paper Scissors game built with Python.

## Description

This project is a command-line game where the player competes against the computer. The computer randomly chooses between rock, paper, and scissors.

## Features

- Random computer choices
- User input validation
- Win, lose, and draw detection
- Score tracking
- Final score display
- Exit the game using `q`

## Technologies Used

- Python 3
- `random` module

## How to Run

1. Make sure Python is installed.
2. Download or clone this repository.
3. Open the project folder.
4. Run the following command:

```bash
python game.py
```

## How to Play

- Enter `rock`, `paper`, or `scissors` to play.
- The computer randomly selects its choice.
- The winner of each round earns one point.
- Enter `q` to quit the game and see the final score.
